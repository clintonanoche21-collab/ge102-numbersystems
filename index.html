Number Systems: Decimal, Binary, Octal and Hexadecimal

GE102 Mathematics in the Modern World · Self-paced module · about 60 minutes

Lesson 1: What is a number system?

8 minutes

By the end of this module you can: name the four common number systems, convert any of them to decimal, convert decimal to any of them, and switch quickly between binary, octal and hexadecimal.

DefinitionA number system is a way of writing numbers using a fixed set of digits. The base (or radix) is how many different digits it uses. Each position in a number has a place value, which is a power of the base.
SystemBaseDigits usedWhere you see it
Decimal100 1 2 3 4 5 6 7 8 9Everyday counting, money
Binary20 1Inside computers (off/on)
Octal80 1 2 3 4 5 6 7File permissions, older computers
Hexadecimal160–9 and A B C D E FColors (#FF8800), memory addresses

You already know place value

In decimal, the number 2025 means 2 thousands, 0 hundreds, 2 tens and 5 ones. Each place is 10 times bigger than the place on its right.

Big ideaEvery number system works the same way. Only the base changes. In base 2 each place is 2 times bigger, in base 8 it is 8 times bigger, in base 16 it is 16 times bigger.

Notation: we write the base as a small number after the value. 1011₂ is binary, 275₈ is octal, 2AF₁₆ is hexadecimal, and 45₁₀ is decimal.

Lesson 2: Meet binary, octal and hexadecimal

8 minutes

Binary (base 2)Uses only 0 and 1. Place values are 1, 2, 4, 8, 16, 32, …
Octal (base 8)Uses digits 0 to 7. Place values are 1, 8, 64, 512, …
Hexadecimal (base 16)Needs 16 symbols, so after 9 it uses letters: A = 10, B = 11, C = 12, D = 13, E = 14, F = 15. Place values are 1, 16, 256, 4096, …

Counting side by side

Notice that when a system runs out of digits, it adds a new place, just like 9 becomes 10 in decimal.

Check yourselfIs 28₈ a valid octal number? No. The digit 8 does not exist in octal, so the largest digit is 7. Is 1201₂ valid? No. Binary only allows 0 and 1.

Method: multiply and add1) Write the place values from the right: 1, base, base², … 2) Multiply each digit by its place value. 3) Add all the products. The total is the decimal value.

TipThe rightmost digit always has place value 1 (because any base to the power 0 equals 1). Count places from the right, starting at power 0.

Going “back” to another systemTo go from, say, octal to binary, you can convert to decimal first (Lesson 3), then from decimal to binary (this lesson). The next lesson shows a faster shortcut.

Lesson 5: Shortcuts between binary, octal and hexadecimal

10 minutes

Since 8 = 2³ and 16 = 2⁴, one octal digit equals exactly 3 bits and one hexadecimal digit equals exactly 4 bits. No division needed.

Binary to octal: group by 3 from the right

Example: 101110110₂. Convert each group of 3 bits (weights 4, 2, 1).

Binary to hexadecimal: group by 4 from the right

Example: 11010111₂. Weights in each group are 8, 4, 2, 1.

If the left group is short, add zeros on the left. For 101101₂ in hex: 0010 1101 = 2D₁₆.

Octal to binary: expand each digit to 3 bits

Hexadecimal to binary: expand each digit to 4 bits

Octal ↔ hexadecimal: use binary as the bridge

Example: A5₁₆ to octal. First A5₁₆ = 1010 0101. Regroup by 3: 010 100 101 = 245₈.

Memory aidLearn the 4-bit patterns for 0 to 15 from the counting table in Lesson 2. After a little practice you can convert hex and binary in your head.
